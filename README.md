# Pattern-based DSA Practice using LeetCode

This repository is focused on learning DSA in a structured way—one pattern at a time.

It serves as a personal reference for revision, with solutions organized by pattern and approach. The goal is to recognize common patterns, understand different approaches, and improve problem-solving skills rather than simply collecting solutions.

Hopefully, it can be useful for others learning DSA as well.

## Repository Structure

- Each folder represents a DSA pattern (Arrays, Prefix Sum, Sliding Window, Binary Search, Stack, Queue, etc.).
- Inside every pattern folder are leetcode problems related to that pattern.
- Each problem has its own folder containing one or more solution approaches.

## What's Included

- Solutions written with clarity, comments, and best practices 
- Multiple approaches whenever applicable
- Well-commented C++ solutions
- Time and Space Complexity analysis
- Clean folder structure for easy navigation
- Pattern-wise learning and practice

### Goal

The idea is not just to solve problems, but to understand how different approaches evolve from brute force to more optimized solutions.

## Work in Progress

This repository is still growing. I'll keep adding new patterns, problems, and approaches as I continue learning and practicing.
